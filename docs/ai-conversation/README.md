# AI 协作对话记录

本目录归档本项目从**一句中文题目**到**一个可运行工程**的完整 AI 协作过程。

| 文件 | 说明 | 大小 |
| --- | --- | --- |
| `对话记录.md` | 人读版：会话元信息 + 逐轮对话 + 工具调用 + 系统事件附录 | ~0.6 MB |
| `对话记录-原始事件.jsonl.zst` | 逐条原始事件（1592 条），保留原始序号与时间戳，zstd 压缩 | ~1.3 MB（解压后 ~7.9 MB） |
| `export-conversation.mjs` | 导出脚本，可重复运行，每次覆盖上面两份 | — |

## 怎么核对

原始事件解压后约 7.9 MB，GitHub 不会渲染这么大的文本文件，所以压缩存放。解压一行命令（Node 18+ 自带 zstd 需要 Node 22.15+/24）：

```bash
node -e "const z=require('node:zlib'),f=require('node:fs');f.writeFileSync('events.jsonl',z.zstdDecompressSync(f.readFileSync('对话记录-原始事件.jsonl.zst')))"
```

得到的 `events.jsonl` 每行是一条事件，字段 `seq` 是原始序号，可与 `对话记录.md` 逐条对照。

## 数据来源与可信度

- 来源是 **DSH 运行时的事件日志** `session.v3.jsonl.zstd`，不是事后人工整理的纪要。脚本自动定位该文件。
- 该日志是**追加写的多帧 zstd**（本次共 913 帧）。常规解压（`zstdDecompressSync` / `createZstdDecompress`）**只吃第一帧**——本项目的导出脚本按魔数 `28 B5 2F FD` 切帧、逐帧解压，才拿到全部记录。
- 导出**未经人工改写**。折叠块内的内容为可读性做了截断（助手思考 900 字、工具返回 700 字、工具参数 600 字），完整内容在原始事件文件里。
- 脱敏：本会话中出现过一次 GitHub PAT（用于一次性发布）。导出时已抹掉，共 **32 处**；该 token 事后已吊销。另覆盖 `sk-` / `github_pat_` / `AKIA` 等通用凭据形态。

## 如实说明的局限

1. **整个项目在一次会话内完成**，时间跨度约 **5 小时 40 分**（17:37—23:21，北京时间）。这是真实情况，我们没有拉长时间线。它说明的是「一次高强度协作」，而不是「跨天多次迭代」——请按实际情况评估。
2. 折叠块经过截断，只有原始事件文件是全文。
3. 日志里混有**系统注入的上下文**（运行时快照、技能目录、子代理完成通知），它们同样落在 `user/message` 事件下。导出时被识别并单独标记为「⚙️ 系统注入上下文」，**没有删除**——保留完整性，同时让读者一眼看到人真正说了什么。
4. 会话仍在继续，本目录内容是某个时点的快照。需要最新版本就重新运行导出脚本。
